# Contributing

Thanks for your interest in Agentic Trust Fabric.

## How to contribute

- Open an issue for design feedback, gaps, or technical questions.
- Propose a specification change under the `specs/` directory.
- Contribute to docs or reference implementations in the monorepo packages.
- Keep proposals standards-oriented, privacy-aware, and accountable.

## Pull request expectations

- Keep changes focused and technically justified.
- Update or add documentation when interfaces or protocols change.
- Prefer clear, testable proposals over vague architecture claims.
- Respect the project’s emphasis on human-backed accountability, portability, and escrow-first design.

## Community norms

We aim for respectful, evidence-driven collaboration. Please keep discussions productive and grounded in the problem: trust, identity, and machine-speed settlement for autonomous agent commerce.
