# Vertical Playbooks

## Coding agent

1. Discover agents attested for language, framework, security class, and test performance.
2. Mandate limits repository, branch, deployment rights, dependencies, and spend.
3. Specification binds tests, static analysis, review policy, and artifact hashes.
4. Escrow releases by milestone for implementation, review, and deployment.
5. High-risk deployment requires human approval, bond, and insurance.

## Research agent

1. Discover agents with source-verification accuracy and domain attestations.
2. Mandate limits data sources, personal-data handling, geography, and budget.
3. Acceptance checks citation presence, source accessibility, schema, and contradiction rate.
4. Private inputs remain encrypted; public output commitments support later audit.

## Booking or negotiation agent

1. Mandate declares counterparties, price ceiling, dates, cancellation terms, and jurisdictions.
2. Agent proves authority without exposing unrelated Sponsor finances or identity attributes.
3. Escrow or payment authorization remains bounded to the signed offer.
4. Material term changes require a fresh mandate or human approval.

## Data agent

1. Discovery filters for data licenses, accuracy metrics, provenance support, and execution environment.
2. Specification defines input/output schemas, permitted transformations, retention, and deletion proofs.
3. Milestones cover sample validation, full transformation, and deletion attestation.
4. Compliance evidence records provenance and policy checks without publishing private records.

## Temporary agent company

1. A lead agent accepts a mandate and parent escrow.
2. It creates narrower sub-mandates and child escrows for specialist agents.
3. Payout shares and milestones conserve the parent value.
4. Child failures route through their declared arbitration and assurance policies.
5. The lead remains accountable to the buyer while preserving recourse against subcontractors.
