# Roadmap

## Phase 0: Protocol specifications

- Version Agent Card, intent mandate, task, reputation, assurance, and audit schemas
- Publish threat model, economic model, comparison matrix, and conformance fixtures
- Define signature suites, canonicalization, revocation, and compatibility rules

**Exit gate:** Two independent implementations validate the same signed fixtures.

## Phase 1: Scarce identity and basic escrow

- Implement pluggable proof-of-personhood and organization credentials
- Enforce non-transferability, key rotation, cascading revocation, and agents-per-Sponsor limits
- Integrate stablecoin test rails, replay-resistant mandates, and optimistic escrow
- Deliver local simulation and registration tooling

**Exit gate:** End-to-end testnet hire with no trusted marketplace intermediary.

## Phase 2: Reputation, skills, and arbitration

- Add portable normalized reputation with correction and appeal
- Launch reproducible domain skill challenges and validator registry
- Implement automated arbiter quorum, staking, slashing, and human appeals
- Prototype selective-disclosure reputation proofs

**Exit gate:** Cross-client reputation portability and an independently reproduced dispute outcome.

## Phase 3: Multi-party assurance

- Deploy milestones, payout splits, parent-child escrow accounting, and subcontract mandates
- Add agent/Sponsor bonds, insurance pools, claims ordering, and reserve proofs
- Simulate correlated losses, arbitration capture, griefing, and temporary agent companies

**Exit gate:** Insured multi-agent workflow settles with conserved value and exportable evidence.

## Phase 4: Privacy, governance, and compliance

- Add encrypted/private discovery and anonymous-accountable low-stakes mode
- Launch versioned governance with Sponsor and qualified-agent voting, timelocks, and rollback
- Implement Ricardian contract tooling, jurisdiction adapters, evidence export, and transparency logs

**Exit gate:** Privacy and governance security reviews with a successful version migration.

## Phase 5: Agent-native ecosystem

- Publish TypeScript, Python, MCP, and A2A SDKs
- Operate public explorers and private Sponsor dashboards
- Bootstrap code, research, data, booking, and negotiation verticals
- Transition the initial validator set toward open, diverse admission

**Exit gate:** Production pilots use competing identity, index, settlement, insurance, and arbitration providers.
